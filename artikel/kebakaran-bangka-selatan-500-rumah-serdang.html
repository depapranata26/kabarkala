Api dari lahan kering merambat ke rumah warga

Ratusan rumah terdampak

Data sementara BPBD Kepulauan Bangka Belitung per Minggu (11/10) pukul 07.00 WIB: sekitar 500 rumah di Dusun Serdang, Desa Jelutung II, Kecamatan Simpang Rimba, terdampak kebakaran. Totalnya sekitar 500 KK atau 2.000 jiwa yang terdampak.

3 / 6
⏱️

Awal mula api

Kebakaran pertama kali dilaporkan Sabtu (10/10) sekitar pukul 15.10 WIB, bermula dari lahan kering di dekat permukiman. Angin kencang dan rumah warga yang mayoritas berdinding papan bikin api menjalar super cepat. Api baru berhasil dipadamkan Minggu pagi, dan petugas masih melakukan pendinginan.

4 / 6
🙏

Tanpa korban jiwa

BPBD memastikan tidak ada korban jiwa dalam peristiwa ini. Warga yang kehilangan tempat tinggal mengungsi ke SDN 7 Simpang Rimba (sekitar 60 orang) atau menumpang di rumah kerabat. Tenda BPBD dan dapur umum Dinas Sosial disiapkan di halaman sekolah.

5 / 6
🚑

Pemerintah daerah turun tangan

Wakil Bupati Bangka Selatan Debby Vita Dewi bersama Kapolres Bangka Selatan memantau langsung penanganan di lokasi pada Sabtu malam. Posko pengungsian dan bantuan logistik disiapkan untuk warga terdampak sementara pendataan masih berjalan.

Efeknya ke lo apa?

Musim kemarau bikin karhutla gampang banget nyebar — dari lahan kering bisa sampai ratusan rumah. Kalau mau bantu, salurkan donasi lewat relawan atau lembaga resmi di Bangka. Dan pelajaran paling simpel: jangan bakar sampah atau lahan kering, api kecil bisa jadi petaka besar.
