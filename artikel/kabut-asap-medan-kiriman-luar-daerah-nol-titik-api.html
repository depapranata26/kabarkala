Asapnya kiriman, bukan dari Sumut

Dinas LHK Sumut pastikan nol titik api di Sumut — asap di Medan terbawa angin dari luar daerah. Geser →

2 / 6
🔥

Nol titik api di Sumut

Kepala Dinas LHK Sumut Heri Wahyudi Marpaung menegaskan, berdasarkan data BMKG, tidak ada lagi titik api kebakaran hutan dan lahan di Sumatera Utara. Dua titik api yang sempat terdeteksi di Asahan dan Samosir sekitar satu setengah bulan lalu sudah berhasil dipadamkan.

3 / 6
💨

Asapnya ikut angin dari luar

Kabut asap yang menyelimuti Medan dan Sumut adalah asap kiriman dari luar daerah, terbawa pergerakan angin. Karhutla nasional saat ini didominasi kebakaran lahan gambut di Kalimantan, Sumatera Selatan, Jambi, Lampung, dan Riau.

4 / 6
📊

Udara Medan sempat tidak sehat

Kamis (15/10) pagi, ISPU di Jalan Pinang Baris mencapai 117 dan di Jalan A.H. Nasution 113 — keduanya kategori tidak sehat. Jarak pandang di sejumlah titik Sumut menyusut jadi 1–4 kilometer, dan BMKG mengimbau pengendara mengurangi kecepatan, menjaga jarak aman, dan menyalakan lampu.

5 / 6
😷

Masker dibagikan di mana-mana

Pemko Medan menyiagakan puskesmas dan membagikan 1.800 kotak masker ke masyarakat, sementara Lurah Sari Rejo membagikan sekitar 500 masker ke pengguna jalan. Dinas Kesehatan Sumut meminta kabupaten/kota meningkatkan pencegahan dan membagikan masker PM2.5 ke warga.

6 / 6
🤔

Efeknya ke lo apa?

Asap kiriman = sumbernya di luar kendali kita, tapi paru-paru lo tetap yang kena. Selama udara masih pekat: pakai masker kalau keluar, kurangi aktivitas outdoor, tutup jendela — dan kalau mata/pernapasan mulai perih, jangan disepelekan, langsung ke puskesmas. 😷
