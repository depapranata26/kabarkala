Api Muncul Sejak Kamis Sore

Titik api di lereng Gunung Arjuno muncul sejak Kamis (15/10) sore di Blok Gumandar, Desa Jatiarjo, Kecamatan Prigen, pada ketinggian sekitar 2.100 mdpl. Hingga Jumat malam, api masih berkobar.

3 / 6
🗺️

Bukan Satu Titik Doang

Api juga terpantau di Gunung Ringgit (900 mdpl, kawasan Perhutani Desa Dayurejo) dan Bukit Nogo (900 mdpl, Desa Tambaksari). Gunung Kukusan di Pegunungan Anjasmoro bahkan sudah terbakar sejak 13 Oktober.

4 / 6
🧑‍🚒

Tim Gabungan Dikerahkan

BPBD Jawa Timur, BPBD kabupaten/kota, TNI Kodim 0819 Pasuruan, petugas Tahura Raden Soerjo, dan relawan bergerak memadamkan api lewat jalur darat. Di Blok Gumandar saja, 11 personel diterjunkan: 4 petugas Tahura dan 7 relawan.

5 / 6
🚫

Jalur Pendakian Ditutup Sementara

Demi keselamatan, seluruh jalur pendakian Gunung Arjuno dan Welirang ditutup total untuk sementara waktu. Pendakian via Bukit Cendono juga ditutup. Medan terjal dan angin kencang bikin pemadaman makin berat.

Efeknya ke lo apa?

Punya rencana naik Arjuno atau Welirang dalam waktu dekat? Tunda dulu, jangan maksain. Musim kering + angin kencang bikin api gampang nyebar — satu puntung rokok atau api unggun yang nggak padam bisa jadi bencana.
