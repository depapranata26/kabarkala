Laga Malam Ini di Jatidiri

Java United menjamu Bali United pada pekan kelima BRI Super League 2026/2027, Jumat 16 Oktober 2026 pukul 19.00 WIB di Stadion Jatidiri, Semarang. Laga ini disiarkan langsung Indosiar dan Vidio.

Tribun Barat: Rp150 Ribu Jadi Rp27 Ribu

Manajemen Java United menjual tiket Tribun Barat seharga Rp27 ribu, turun dari harga normal Rp150 ribu, dengan kuota terbatas. Tiket bisa dibeli lewat situs resmi klub javaunited.com atau kanal resmi Instagram @java.utd.

Gratis Buat Ponpes dan SSB

Java United juga menyediakan kuota gratis untuk pondok pesantren dan SSB (Sekolah Sepak Bola). Menurut manajer Alan Haviludin, promo ini dihadirkan agar publik, terutama warga Jawa Tengah, bisa terus menikmati pertandingan di stadion.

Dua Tim Sama-Sama Habis Menang

Java United datang dengan modal kemenangan 2-1 atas Borneo FC lewat gol Kaio Nunes dan Lucas Brambilla. Bali United lebih garang: menang 6-1 atas Persijap Jepara, dengan Jort van der Sande mencetak hattrick. Bali United kini di tiga besar klasemen dengan 9 poin, sementara Java United di peringkat ke-13.
