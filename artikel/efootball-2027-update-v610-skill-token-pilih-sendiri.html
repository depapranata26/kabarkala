Select Skill Token: goodbye skill random!

Kumpulkan 100 token untuk mengajarkan 1 skill pilihanmu dari Skill Training — nggak ngandelin RNG lagi. Advanced Skill Token resmi dihapus; sisa token lama dikonversi otomatis, 1 Advanced = 20 Select.

Select Position Token

Mirip versi skill-nya: kumpulkan 100 token buat mempelajari Position Proficiency pilihan dari posisi yang tersedia untuk pemain tersebut. Skuad makin bisa disetel sesuai taktik lo.

Mode gugur "Showdown" + kampanye Inter

Event PvP baru Showdown: turnamen knockout — kalah sekali = gugur, menang terus = hadiah makin gede. Hari pertama dijadwalkan 16 Oktober 2026. Lewat Campaign Hub, bisa dapat hingga 5 pemain Inter (termasuk 3 dengan Playing Style baru) sampai 22 Oktober.

4 Playing Style baru + tampilan makin sinematik

Hadir Press Back (penyerang ikut pressing), Build-up GK (kiper ikut build-up), Deep Defender, dan Tough Marker. Presentasi diperbarui: Referee View ala siaran TV, Player View di momen penting kayak free kick & pergantian, plus animasi dan perayaan gol baru. Pack baru: Epic Spanish League Guardians (Marcelo, Pepe, Edmilson).
